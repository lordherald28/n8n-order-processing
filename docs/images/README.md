# Capturas verificadas

Este directorio está reservado para capturas reales y anonimizadas de n8n y Telegram. No contiene imágenes porque no había capturas disponibles para esta entrega; no se generan mockups ni evidencias ficticias.

Antes de añadir una imagen, recorta y elimina nombres, correos, IDs de chat, tokens, URL pública temporal, datos de pedidos y cualquier otra información identificable. Mantén únicamente la parte de la interfaz necesaria para explicar el flujo.
