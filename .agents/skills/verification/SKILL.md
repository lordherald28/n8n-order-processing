# Verification

- Ejecuta pruebas reproducibles y apropiadas para el objetivo autorizado.
- Registra los comandos, resultados reales y errores relevantes; distingue lo ejecutado de lo pendiente.
- Si las verificaciones del objetivo fallan, no lo marques como completado ni crees un commit para ese objetivo.
- Informa cualquier bloqueo o limitación en el resumen del objetivo.
