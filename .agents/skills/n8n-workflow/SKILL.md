# n8n workflow

- Trabaja con n8n 2.47.7 ejecutado en Docker.
- Crea workflows reales dentro del alcance autorizado, pruébalos y expórtalos como JSON al proyecto.
- No modifiques workflows existentes ajenos al proyecto ni expongas credenciales o secretos.
- Pide autorización antes de cambiar Docker, instalar componentes o desplegar, conforme a `AGENTS.md`.
