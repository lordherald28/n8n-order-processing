# ODD cycle

- Divide el trabajo autorizado en objetivos pequeños y define criterios de aceptación observables para el objetivo actual.
- Trabaja únicamente en el objetivo actual; no comiences otro hasta recibir «listo» del usuario.
- Sigue `AGENTS.md` y `git-flow.md` para alcance, ramas, aprobaciones y commits.
- Completa el ciclo implementar → probar → verificar → commit. Aplica la skill `verification` para evidencias y la skill `n8n-workflow` cuando el objetivo afecte workflows.
- No registres un commit para un objetivo que no haya superado sus verificaciones.
